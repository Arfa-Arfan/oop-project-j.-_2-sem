# 👕 J. Clothing Store Management System

A C++ based console application that simulates a real-world clothing and lifestyle store inspired by **Junaid Jamshed (J.)**. Built using **Object-Oriented Programming (OOP)** concepts.

## 📋 Features

### 👑 Admin Panel
- Admin login system
- Add new products (Watches, Shoes, Bags, Dresses, Perfumes)
- Update/Delete existing products
- View complete inventory
- Track customer orders

### 🛍️ Customer Panel
- Register/Login system
- Browse products by categories
- Filter by size and price
- Add/Remove items from cart
- Checkout with bill generation
- Real-time stock updates

## 🏗️ OOP Concepts Used

| Concept | Implementation |
|--------|----------------|
| Classes & Objects | Product, Customer, etc. |
| Inheritance | Admin/Customer inherit from User |
| Polymorphism | Virtual functions for display |
| Encapsulation | Private members with public getters |
| Abstraction | Pure virtual functions |
| File Handling | Save/Load product data |

## 🛠️ Technologies

- **Language:** C++
- **Tools:** Code::Blocks, Dev-C++, VS Code
- **Storage:** File-based (products.txt)
